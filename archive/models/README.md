# 📦 Archived Pretrained Models (ประวัติโมเดลเดิม)

โฟลเดอร์นี้เก็บสำรองไฟล์โมเดล TFLite INT8/UINT8 ที่เคยผ่านการทดสอบในรอบก่อนหน้า เพื่อใช้อ้างอิงหรือเปรียบเทียบผลกับโมเดลเวอร์ชันใหม่

---

## 📋 รายการโมเดลที่จัดเก็บ

| ชื่อไฟล์โมเดล | ขนาดไฟล์ | คำอธิบาย / รายละเอียด |
| :--- | :--- | :--- |
| `mangosteen_cnn_10k_uint8in.tflite` | 18.5 KB | โมเดล Compact CNN ขนาดเล็กพิเศษ (~10,000 parameters) ความเร็วสูง |
| `mangosteen_cnn_20k_uint8in.tflite` | 28.3 KB | โมเดล Balanced CNN (~20,000 parameters) |
| `mangosteen_cnn_90plus_uint8in.tflite` | 80.1 KB | โมเดล CNN ที่ผ่านการปรับแต่งค่าความแม่นยำสูง (>90% accuracy target) |

---

> 💡 **หมายเหตุ:**  
> หากต้องการนำโมเดลเก่าตัวใดตัวหนึ่งกลับมาแฟลชทดสอบบนบอร์ด ESP32-S3 สามารถคัดลอกไฟล์โมเดลนั้นกลับไปไว้ที่โฟลเดอร์ `models/` แล้วรัน `python setup.py` ได้ทันที
