# 📁 Dataset Workspace (พื้นที่จัดวางชุดข้อมูลสำหรับเทรนใหม่)

โฟลเดอร์นี้จัดเตรียมไว้สำหรับใส่รูปภาพผลมังคุดสำหรับการเทรนโมเดลรอบใหม่ โดยแบ่งโครงสร้างตามมาตรฐานของ TensorFlow / Keras ดังนี้:

---

## 🗂️ โครงสร้างโฟลเดอร์

```text
dataset/
├── train/          # ข้อมูลสำหรับใช้สอนโมเดล (แนะนำ ~70% ของภาพทั้งหมด)
│   ├── overripe/   # ภาพมังคุดสุกงอม / เปลือกคล้ำดำด้าน / สุกเกิน
│   ├── ripe/       # ภาพมังคุดสุกพอดีกิน / เปลือกม่วงแดง
│   └── unripe/     # ภาพมังคุดดิบ / เปลือกเขียวหรือมีสายเลือด
├── val/            # ข้อมูลสำหรับตรวจสอบระหว่างเทรน (Validation ~15%)
│   ├── overripe/
│   ├── ripe/
│   └── unripe/
└── test/           # ข้อมูลสำหรับทดสอบวัดผลขั้นสุดท้าย (Test ~15%)
    ├── overripe/
    ├── ripe/
    └── unripe/
```

---

## 📸 ข้อแนะนำในการเตรียมภาพ

1. **สัดส่วนภาพและขนาด:**
   - โมเดลจะทำการ Resize ภาพเป็น **96 × 96 พิกเซล** อัตโนมัติในขั้นตอนเทรน
   - แนะนำให้รูปถ่ายมีสัดส่วน 1:1 หรือผลมังคุดอยู่ตรงกลางภาพ
2. **ความหลากหลายของมุมมองและแสง:**
   - ถ่ายภาพมังคุดจากหลายมุม (ด้านบนเห็นขั้ว, ด้านข้าง, ด้านก้น)
   - ถ่ายในสภาพแสงทั้งแสงธรรมชาติ แสงในร่ม และแสงหลอดไฟ
3. **การเริ่มเทรน:**
   - **เทรนบน Google Colab:** สามารถ Zip โฟลเดอร์ `dataset` นี้เพื่อนำไปอัปโหลดบน Colab ได้ทันที
   - **เทรนบนเครื่องตัวเอง (Local):** เมื่อวางภาพเสร็จแล้ว รันคำสั่ง:
     ```bash
     python training/train_edge_model.py
     ```
